# marked below can also be flashed from the Upload button today. Defaults are
# chosen to be the safe answer, not the fastest one:
#
#   Optimize        Size   -- these parts run out of flash long before cycles
#   Debug info      None   -- symbols cost build time and disk, not flash
#   Compiler        Auto   -- PATH, then the usual install directories
#
# Programmer lives in Tools > Programmer (programmers.txt).
